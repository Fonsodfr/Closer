=====================================================
 CLOSER for macOS - test version
 Rave Factory · 3-band stereo width control
=====================================================

ENGLISH
-------

1. Double-click Closer-Installer.pkg

   macOS will say it cannot verify it. Click "Done" (or "OK").
   This test version is not signed by Apple yet. That is normal.

2. Allow it

   Open System Settings > Privacy & Security.
   Scroll down: you will see "Closer-Installer.pkg was blocked".
   Click "Open Anyway" and enter your Mac password.

3. Install

   The installer opens: Continue > Install. Done.
   (Click "Customize" if you only want the VST3 or only the Audio Unit.)

4. Open your DAW

   Restart your DAW and rescan plugins if needed.
   It appears as "Closer" by "Rave Factory".

If you installed an earlier test version by hand, delete these
first so you do not have two copies:
   ~/Library/Audio/Plug-Ins/VST3/Closer.vst3
   ~/Library/Audio/Plug-Ins/Components/Closer.component

ESPAÑOL
-------

1. Haz doble clic en Closer-Installer.pkg

   macOS dirá que no lo puede verificar. Pulsa "OK" (o "Aceptar").
   Esta versión de prueba aún no está firmada por Apple. Es normal.

2. Permítelo

   Abre Ajustes del Sistema > Privacidad y seguridad.
   Baja hasta abajo: verás "Se ha bloqueado Closer-Installer.pkg".
   Pulsa "Abrir igualmente" y escribe la contraseña de tu Mac.

3. Instala

   Se abre el instalador: Continuar > Instalar. Listo.
   (Pulsa "Personalizar" si solo quieres el VST3 o solo el Audio Unit.)

4. Abre tu DAW

   Reinicia tu DAW y, si hace falta, vuelve a escanear los plugins.
   Aparece como "Closer" de "Rave Factory".

Si instalaste a mano una versión de prueba anterior, borra antes
estas dos para no tener el plugin repetido:
   ~/Library/Audio/Plug-Ins/VST3/Closer.vst3
   ~/Library/Audio/Plug-Ins/Components/Closer.component
